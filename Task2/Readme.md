# 📌 Project Overview

The AI Recommendation System allows users to enter their interests and receive intelligent recommendations based on similarity matching logic.

The system analyzes user preferences and compares them with predefined item tags to generate personalized recommendations.

---

# ✨ Features

* Professional console interface
* User preference input
* Similarity matching algorithm
* Recommendation scoring system
* Pattern recognition logic
* Dynamic recommendations
* Clean and structured Python code

---

# 🧠 Recommendation Logic

The system uses a simple AI recommendation strategy:

\text{Similarity Score} = \text{Count of Matching Interests Between User Preferences and Item Tags}

Higher similarity scores result in better recommendations.
